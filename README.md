# Toucan — Free Offline Installer

![Category](https://img.shields.io/badge/Sync_and_Backup-blue?style=flat-square)

## About

Toucan is a free, open-source portable backup, sync, and encrypt utility for Windows. Create sync jobs to keep folders mirrored, back up to local or network drives with compression and encryption, and run jobs from a USB drive without installation. Toucan's portable design and scheduled task support make it a flexible backup solution for users who want simple, powerful local backup without cloud dependency.

## Common Problems & Limitations

- **Windows Only** — No cross-platform version
- **Dated Interface** — Visual design reflects the software's age
- **Development Status** — Development pace has slowed significantly
- **Feature Scope** — Basic sync and backup; less comprehensive than major backup solutions
